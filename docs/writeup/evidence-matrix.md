## Status Legend

| Marker | Meaning |
|---|---|
| Implemented | Evidence is current and the linked check passes. |
| Partially verified | Static evidence is current but a live check still depends on operational state (e.g. CLI auth). |
| Blocked | A prerequisite is missing or has regressed and prevents the row from being marked Implemented. |

Completion rule: the goal is not complete until the blocked Claude Code auth and live `verify-arms` rows have concrete current evidence. `npm run check:completion -- --run <final-run> --trials 5` is the executable audit for that rule.
